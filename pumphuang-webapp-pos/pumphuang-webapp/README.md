# ระบบรถพุ่มพวงออนไลน์ (เวอร์ชันปรับปรุง)

## วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `pumphuang-webapp` ใน VS Code
3. เปิด `index.html` ผ่านส่วนขยาย Live Server (แนะนำ) หรือเปิดไฟล์ในเบราว์เซอร์

## ไฟล์
- `index.html` โครงหน้าเว็บ
- `style.css` รูปแบบและ Responsive UI
- `app.js` ระบบรถ สินค้า ตะกร้า ออเดอร์ ผู้ขาย และรายงาน

## บัญชีตัวอย่าง
- ผู้ขาย: `seller` / `1234`
- ลูกค้า: `cutomer` / `1234`

บัญชีตัวอย่างใช้เพื่อทดสอบเท่านั้น ให้เปลี่ยนรหัสผ่านหรือเอาออกก่อนนำเสนอในที่สาธารณะ

## สิ่งที่ปรับปรุง
- ลบ `showRegister()` ที่ซ้ำกัน
- เพิ่ม `registerUser()` ที่เดิมถูกเรียกใช้แต่ไม่มีการประกาศ
- สมัครสมาชิกใหม่ได้เฉพาะบทบาทลูกค้า ไม่สามารถเลือกบทบาทผู้ขายเอง
- เพิ่มการตรวจสอบสิทธิ์ก่อนเปิดหน้าจัดการผู้ขาย
- เพิ่มค้นหาและเรียงลำดับสินค้า
- เพิ่มกราฟยอดขายย้อนหลัง 7 วันในแดชบอร์ดผู้ขาย
- เพิ่มการตรวจสอบไฟล์สลิปและจำกัดขนาดไฟล์ 2 MB
- ป้องกันการยืนยันชำระเงินซ้ำเพื่อรับแต้มซ้ำ
- ปรับวันที่เป็นเวลาท้องถิ่น และเพิ่ม Responsive CSS

## ข้อจำกัดด้านความปลอดภัย
นี่เป็นโครงงาน Frontend ล้วน ข้อมูลและรหัสผ่านยังเก็บใน LocalStorage และตรวจสิทธิ์ด้วย JavaScript จึงไม่ปลอดภัยสำหรับใช้งานจริง ผู้ใช้สามารถแก้ข้อมูลผ่าน Developer Tools ได้ หากนำไปใช้งานจริงต้องเพิ่ม Backend/API, ฐานข้อมูล, password hashing, session/token, server-side authorization และตรวจสอบการชำระเงินที่ฝั่งเซิร์ฟเวอร์
